# Досье персонажей «Моя геройская академия» (My Hero Academia) — общий указатель

> Набор для офлайн-работы: подробные досье в формате коротких фактов на учеников классов 1-А и 1-Б, учителей и администрацию академии Юэй и топ-героев. Каждое досье — не менее 20 000 символов.

- Всего досье: 72.
- Общий объём: ~1 526 082 символов (без учёта этого указателя).
- Формат: Markdown (UTF-8). Каждый файл самодостаточен; в конце каждого — общий блок «Примечание к досье» с источниками, легендой пометок и мини-глоссарием.
- Всё одним файлом: `MHA_dossier_FULL.md` (Markdown) и `MHA_dossier_FULL.txt` (простой текст) в этой же папке; архив `MHA_dossier.zip` — все файлы с сохранением структуры.

## Как пользоваться

- Нужен персонаж «на минуту» — читайте «Справочная карточка», «Ядро личности» и «Быстрый старт».
- Нужен голос персонажа — «Речь», «Образцы реплик (перефраз)», «Вопрос — ответ».
- Нужна боевая сцена — «Причуда: механика и ограничения», «Боевой стиль», «Приёмы», «Матчапы».
- Нужна бытовая сцена — «Привычки», «Хобби», «Вкусы», «Один день», «Мелкие факты-крючки».
- Нужно проверить канон — «Ключевые этапы», «Хроника по эпизодам», «Чек-лист соответствия канону».
- Персонажи с животной (и не только) природой причуды — раздел «Повадки…» (список ниже).

## Легенда пометок

- «(канон)» — факт из манги/аниме; «(интерпретация)» — вывод из канонического поведения; «(перефраз)» — реплика по смыслу, не дословно; «(по манге)» — деталь стоит сверить с главой; «AU/хэдканон» — допущение для альтернативных историй.
- Чем меньше персонаж показан в каноне (часть 1-Б, Уош, Ёрои Муся, Фоурт Кайнд, Ланч Раш), тем больше в его досье помеченной интерпретации.
